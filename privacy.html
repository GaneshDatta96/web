Privacy

This site is a static public site for Ganesh R Datta, hosted on GitHub Pages at https://ganeshdatta.me. It describes sales-infrastructure work and the Decision Cost Framework. It does not run user accounts, a store, or a members area.

What is collected

  • Server logs from GitHub Pages / Fastly: standard request metadata (IP, user agent, path) under GitHub's hosting privacy terms.
  • Umami analytics (cloud.umami.is, site id 6db290a3-baab-4785-86c1-b486e5be2816): page views. No advertising cookies, no cross-site tracking for ads.
  • Cal.com if you book a session: name, email, and whatever you type into the booking form, held by Cal.com under their terms. That is how contact happens.
  • Email or GitHub if you write there instead: whatever you send.

This site does not sell personal data, does not run a remarketing pixel, and does not require an account.

What is public

Field notes, the Decision Cost Framework declaration, and agent files (llms.txt, Markdown siblings, schema) are public on purpose. Do not send secrets to those URLs.

Contact about data

Use https://ganeshdatta.me/contact.html or https://cal.com/ganesh-datta-bygktk/sales-throughput-session. There is no automated deletion portal because there is no account database on this origin.
